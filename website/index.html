Управление эмитентами

Добавляйте и удаляйте эмитенты, которые имеют право регистрировать документы в системе.

Экстренный отзыв credential (owner)

Используйте после компрометации ключа эмитента: отзывает конкретный credential, разблокируя держателя для переоформления у нового эмитента.

Добавить нового эмитента
